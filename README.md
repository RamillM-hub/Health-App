# Дневник Здоровья и Заботы ❤️ (PWA)

Персональное веб-приложение для жены с интеграцией в Google Таблицы и поддержкой офлайн-режима.

## 📁 Структура файлов репозитория:
- `index.html` — главное веб-приложение (дизайн «Уютная кото-комната», адаптивный интерфейс под iPhone, 3 состояния котика от времени суток и прогресса, офлайн-очередь).
- `sw.js` — Service Worker для работы без интернета (кеширование ассетов).
- `manifest.json` — PWA-манифест для добавления на домашний экран iOS/Android.
- `our_photo.jpg` — оптимизированное совместное фото.
- `apple-touch-icon.png` — иконка для рабочего стола iPhone (180x180).
- `icon-192.png`, `icon-512.png` — иконки приложения.
- `Code.gs` — скрипт для Google Apps Script с защитой от дублирования записей.

## 🚀 Инструкция по развертыванию на GitHub Pages:
1. Создайте публичный или приватный репозиторий на GitHub (например, `health-diary`).
2. Загрузите в корень все файлы из архива.
3. Откройте **Settings** репозитория → вкладка **Pages**.
4. В разделе **Build and deployment** выберите **Source**: `Deploy from a branch`, ветка `main` / `root`, и нажмите **Save**.
5. Через 1 минуту ваша ссылка будет готова (например: `https://username.github.io/health-diary/`).
